# NYC Yellow Taxi Data Engineering Assignment

## Project Overview

This project focuses on profiling and cleaning the NYC Yellow Taxi trip dataset for January 2021.

The dataset is processed using Python and pandas to identify data quality issues, define cleaning decisions, and apply data cleaning rules.

## Dataset

The project uses the NYC Yellow Taxi January 2021 dataset.

Source: [NYC TLC Yellow Taxi Dataset](https://github.com/DataTalksClub/nyc-tlc-data/releases/download/yellow/yellow_tripdata_2021-01.csv.gz)

## Project Steps

1. Inspect the dataset.
2. Profile the entire dataset in chunks.
3. Identify data quality problems.
4. Document cleaning decisions.
5. Apply cleaning rules and validate the cleaned data.

## Tools and Technologies

- pandas
- Jupyter Notebook
- Git and GitHub

`Lab 3 - Assignment.ipynb`
